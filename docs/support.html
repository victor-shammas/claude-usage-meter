Installing

How do I install it?

Download the DMG, open it and drag Claude Usage Meter into Applications, then open it from there. It lives in the menu bar and has no Dock icon. To start it automatically, click the meter and choose Launch at Login.

The app is running but I can't see the meter

On MacBooks with a notch, macOS hides menu bar items that would sit behind the camera when the menu bar is full. Make room by hiding other items: hold ⌘ and drag icons out of the menu bar, or turn some off in System Settings › Menu Bar. Then quit and reopen Claude Usage Meter.

Which Macs does it run on?

The app needs a Mac with Apple silicon and macOS 26 or later. On other Macs, you can run the Python version from source, which works on macOS with Python 3.9 or later.

I used the old Python script version. How do I switch?

Remove the old login item first, or you'll see two meters:

launchctl unload ~/Library/LaunchAgents/com.claude-usage-menubar.plist
rm ~/Library/LaunchAgents/com.claude-usage-menubar.plist

Then install the app as above.

Menu bar messages

"No token"

The app couldn't find a Claude Code login on this Mac. Click the meter and choose Re-authenticate…, which opens Terminal and runs claude /login. Choose "Claude account with subscription". The meter updates by itself once you've signed in.

"re-auth"

Your Claude Code login has expired and can't be renewed, for example because you signed out elsewhere. Choose Re-authenticate… from the menu to sign in again.

"rate-limited"

Anthropic's usage service asked the app to wait. The app backs off for as long as the service says, sometimes up to an hour, and then resumes on its own. You don't need to do anything.

"err:401", "err:403" or another error

The login token was rejected. Choose Re-authenticate…, or run claude /login in Terminal. If it keeps happening, please open an issue.

Why are there only two numbers in my menu bar, not three?

The third figure (for example F5) appears only when your plan has a separate weekly cap for a specific model. Without one, the app shows the 5-hour and weekly figures only.

Updates

How does the app update?

Once a day it checks GitHub for a new version and offers to install it. You can also choose Check for Updates from the menu at any time. Updates are signed, and the app verifies the signature before installing. Version 1.4.0 can't update itself, so if you have it, download the latest version once by hand.

Removing the app

How do I uninstall it?
  1. Click the meter and turn off Launch at Login, then choose Quit.
  2. Drag Claude Usage Meter from Applications to the Trash.
  3. Optional: remove its preferences with defaults delete io.github.victor-shammas.claude-usage-meter in Terminal.

Your Claude Code login belongs to Claude Code, so it stays where it is.
