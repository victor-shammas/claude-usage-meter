Privacy Policy

Effective date: October 10, 2026

The short version
  • Claude Usage Meter has no accounts, no servers of its own, no analytics and no ads.
  • To show your limits, it sends your Claude Code login token to Anthropic, the company that issued it, and to nobody else.
  • It checks GitHub once a day for app updates.
  • I (the developer) never receive any of your data. The app is open source, so you can check.

This policy explains what the Claude Usage Meter app for macOS ("the app") reads, which servers it talks to, what it stores and what it never does. The app is made by Victor Shammas, an independent developer ("I", "me"), and its source code is public at github.com/victor-shammas/claude-usage-meter.

1. What the app reads

The app needs the login that Claude Code, Anthropic's command-line tool, already keeps on your Mac. It looks for it in these places, in order, and uses the first one it finds:

SourceWhat is read
The macOS KeychainThe item Claude Code saves as Claude Code-credentials: its OAuth access token, refresh token and expiry time. This is where current versions of Claude Code keep your login.
~/.claude/.credentials.jsonThe same login, where older versions of Claude Code saved it.
CLAUDE_OAUTH_TOKEN or ~/.claude_menubar.jsonA token you have put there yourself, if any. Most people never use these.

The app also runs claude --version to learn which version of Claude Code you have, because the usage service expects it.

2. Network use

ServerWhat is sentWhen
api.anthropic.comYour access token, to read your usage percentages and reset times. The service also returns the list of your plan's limits.Every 5 minutes, and when you click Refresh Now.
console.anthropic.comYour refresh token, to get a new access token.Only when the access token has expired, typically every few hours.
github.comAn ordinary web request for the update feed, and the download if you install an update. Like any web request it carries your IP address and the app's name and version, but nothing about your usage or your Claude account.About once a day, and when you choose Check for Updates.

Anthropic handles those requests under Anthropic's Privacy Policy, as it does for Claude Code itself. GitHub serves the updates under the GitHub Privacy Statement.

If Anthropic declines to renew the token, the app may start claude briefly in the background, which makes Claude Code renew its own login. No prompt is sent, so no usage is spent.

3. What the app changes on your Mac

  • Your Claude Code login, when it renews it. Anthropic issues a new token pair on each renewal, so the app writes the new tokens back to where it found them. That way Claude Code stays signed in.
  • The app's own preferences, such as when it last checked for updates, in ~/Library/Preferences/io.github.victor-shammas.claude-usage-meter.plist.
  • Launch at Login is off until you turn it on, and uses the standard macOS login-item service.
  • Re-authenticate writes a one-line script to your temporary folder that opens Terminal with claude /login, and deletes it when it runs.

4. What the app never does

  • No accounts or sign-in of its own.
  • No analytics, telemetry, crash-reporting services, advertising or tracking SDKs.
  • No servers run by me. Nothing is sent to me, or to any third party on my behalf.
  • It never reads your prompts, conversations, code or files.
  • No selling or sharing of data, because I don't have any of your data.

5. Removing the app

Quit the app, turn off Launch at Login in System Settings › General › Login Items, and delete it from Applications. To remove its preferences too, run defaults delete io.github.victor-shammas.claude-usage-meter in Terminal. Your Claude Code login belongs to Claude Code, so it stays where it is. See Support.

6. Changes and contact

If this policy changes, the effective date above changes with it, and the history is public in the app's GitHub repository. Questions: contact+claude-usage-meter@victorshammas.com.
