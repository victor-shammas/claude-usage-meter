Claude Usage Meter
Features Privacy Support

Your Claude limits, always in view.

Claude Usage Meter puts your 5-hour and weekly Claude usage in the Mac menu bar, so you know how much is left before you start the next big task, and when it resets.

Download for Mac Free macOS 26 or later · Apple silicon · Signed and notarized

A meter, not a dashboard.

One glance at the menu bar tells you whether to keep going or wait for the reset. Click it for the details.

Both limit windows

The rolling 5-hour window and the weekly quota, as percentages right in the menu bar, with a progress bar for each in the menu.

Per-model caps

When your plan has a separate weekly cap for a model, such as Fable 5, it gets its own row and menu bar figure. Plans without one never see an empty row.

Reset countdowns

Know exactly when each window resets, down to the minute.

Colored at a glance

Green, yellow, orange, red, so a filling quota is obvious before you open the menu.

Looks after its login

It renews the Claude Code login token it reads when that token expires, and backs off politely if the usage service asks it to wait. If you ever need to log in again, one click opens Terminal with claude /login.

Free and open source

MIT licensed, with the full source on GitHub. It updates itself, and starts at login if you want it to.

How it works

If Claude Code is on your Mac and signed in, there's nothing to set up.

Install

Open the DMG and drag Claude Usage Meter into Applications. It's signed and notarized by Apple, so it opens without warnings.

It finds your login

The app uses the sign-in Claude Code already keeps in your Keychain. No API key, no extra account.

Glance and go

The numbers refresh every five minutes. Turn on Launch at Login from the menu and forget about it.

Talks to Anthropic, and no one else

To show your limits, the app asks Anthropic's usage service, the same one Claude Code uses, with your own Claude Code login. Apart from checking GitHub for updates, it has no other servers, accounts or analytics.

  • No accounts, no sign-in of its own
  • No analytics, tracking or ads
  • Your login token stays in your Keychain
  • Never reads your prompts, chats or code
  • Open source: read exactly what it does
  • About 140 KB of traffic a day

Requirements

  • A Mac with Apple silicon, running macOS 26 or later. Other Macs can run it from source.
  • Claude Code installed and signed in with a Claude subscription (Pro, Max, Team or Enterprise). Usage limits are reported for subscription plans, not API keys.
